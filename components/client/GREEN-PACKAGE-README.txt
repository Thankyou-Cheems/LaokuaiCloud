唠蒯云 · 解压即用测试版

1. 将 ZIP 完整解压到一个固定、可写的文件夹，不要直接在压缩软件里启动。
2. 右键“唠蒯云.exe”选择“以管理员身份运行”，正常确认 Windows UAC。
3. 首次添加 voice.ruikang.wang 输入社区密码；以后恢复社区自动加入虚拟局域网。
4. 程序启动时准备本应用与自有 EasyTier core 的程序路径防火墙规则。
   不关闭防火墙，不覆盖其他软件、管理员或组织配置的阻止规则。

更新：先从托盘退出旧版。将新版解压到同一固定目录，保留 laokuai-chat-data。
从旧单文件版迁移：把新版解压到旧版旁边，使新 EXE 与原 laokuai-chat-data 同级。
请勿同时运行新旧版本，勿覆盖或删除自己的数据目录，也勿把它发给别人。
移动整个文件夹后，新路径的网络规则需要在下次管理员启动时重新准备。

不再使用：在托盘菜单选择“清理本应用网络规则并退出”，成功后再移除文件夹。
只清理由本应用记录且属性匹配的规则；系统提示产生的旧规则和其他软件规则保留。
普通退出会保留规则供下次启动复用。清理后再次启动会按需重新创建规则。
高级清理入口：以管理员权限执行 唠蒯云.exe --cleanup-network-rules。
清理前请先正常退出正在运行的本应用。保留 laokuai-chat-data 内的规则记录再清理。

虚拟局域网与语音独立：退出语音房不会退出联机。游戏使用成员的联机 IPv4 地址。
源码和对应源码材料见 resources/legal/SOURCE-OFFER.json 中的本仓库链接。
本测试版未签名。正常 UAC 仍需确认；第三方防火墙或组织策略可能另有提示。
