# Squad 模式：私有便携版

默认启用，前台进程检测默认启用。没有匹配的前台游戏时待机，普通通话可用。
自动匹配实际 SquadGame/Binaries/Win64 游戏程序，不匹配启动器、反作弊程序或窗口标题。
支持本机自定义 .exe 文件名或完整路径；完整路径更严格。关闭进程检测后，配置键在其他程序中也生效。
默认 B/G/V，支持修改和多键按住；Shift+B 仍匹配 B。通话快捷键冲突拒绝保存。
自己的输入框和快捷键录制不接纳新按键；已接纳的按键要等物理释放。
最后一个键松开至少等待 200ms，然后 Voice 清除旧代 RNNoise 音频、等待新帧、重建持缓冲 DSP 并确认最终音频边界。
按下请求先显示等待，实际 AudioWorklet 零 PCM ACK 后才显示已暂停发送。恢复失败保持关闭并提供重试。
手动/服务器静音和按键说话优先生效，松键不会恢复旧静音布尔值。接收、屏幕音频和采集保持原路径。

输入来自一个既有 uiohook 通道；原生辅助程序只读取前台路径与配置键当前状态，50ms复核释放。
未知桌面/权限/休眠在已保护时关闭发送并显示故障；首次不可用且尚未保护时普通通话继续。
键与进程仅在内存本地判断，不保存历史，不上传。仅可选发送频道级自由麦/PTT、Squad/发送原因枚举。
旧服务器/客户端没有能力时显示未知，不从音量猜测模式。诊断状态不改变服务器静音或权限。
物理事件、浏览器调度、编码/网络/对端缓冲不能零延迟撤销；已发送音频无法撤回。

本轮只在后台使用合成输入、合成 PCM 和 headless Chromium，未读取真实游戏键盘、未录麦、未启动前台客户端。
打包和合成测试成功不等于实际通话、设备切换或游戏负载验收。所有其他音频默认保持已有值。

本包独立 appId local.laokuai.chat；只用 EXE 所在目录 laokuai-chat-data，不读取原版 owner 资料。
分发只发 EXE，不附自己的 laokuai-chat-data。源码/许可证另附完整对应材料；未经代码签名。
