# 新版联机与快捷设置

本轮新增侧栏语音、音频、联机和常规设置入口。唠蒯云变体移除赞助页面及搜索
入口，保留上游 Gryt 作者、许可证和对应源码说明。

## 联机偏好与配置文件

侧栏“联机设置”提供七项偏好。当前默认值：

| 项目 | 默认 | 作用 |
| --- | --- | --- |
| MagicDNS | 开 | 在已认证社区内使用稳定设备域名，失败时仍可复制虚拟 IP |
| 优先低延迟路径 | 关 | 保留既有 EasyTier 路由偏好；启用后采用其低延迟选路 |
| IPv6 | 开 | 允许 EasyTier 使用 IPv6 连接 |
| UPnP | 开 | 尝试路由器端口映射，是否成功取决于路由器 |
| UDP 打洞 | 开 | 尝试 UDP 直连 |
| TCP 打洞 | 开 | 尝试 TCP 直连 |
| UDP 广播转发 | 关 | 有游戏需要广播发现时可以启用 |

修改先在页面暂存，点击保存后下次启动生效，避免游戏中立即重建虚拟网络。
恢复推荐值同样需要保存。导出内容来自已保存值；导入先显示前后差异，确认后
才保存。文件为严格版本化 JSON，最多 8 KiB，缺项、额外字段和错误类型均拒绝。

配置文件不含账号身份、社区密码、成员令牌、设备私钥、真实 IP、路径或中继
授权，不是任意 EasyTier TOML 导入器。社区地址、发行者与安全模式继续由已
认证的社区管理，不能通过导入替换。换电脑后仍需要正常加入社区。

## MagicDNS 与成员地址

社区拥有独立的随机后缀，每个已认证设备拥有稳定随机主机名；同一账号多设备
分别显示。名称持久绑定服务器设备记录，不跟着昵称变化，也不表示该设备在线。
成员列表显示可复制的域名与虚拟 IP；仅在本机 DNS 准备成功、目录仍新鲜时显示
可用域名。旧后端、不支持的系统或规则冲突时保留数字 IP。

Windows 使用本应用回环解析器与限定社区后缀的 NRPT 规则。解析器不转发公网
查询；退出移除自有 DNS 规则，崩溃后按持久账本恢复清理。清理只匹配本应用
随机归属标识及完整属性，遇到第三方或重叠规则报不可用，不覆盖系统规则。
正常退出保留两条应用防火墙规则供复用；托盘清理入口删除经过归属验证的规则。

## 实验性成员中继

默认关闭，按当前账号、社区和设备保存用户主动选择，独立于上述导入导出。
开启后还需要后端资格确认、新 core/CLI 能力回读、新鲜本机状态及有限短租约；
界面“可协助”表示这些条件已确认，不等于正在转发或整条路径都是成员节点。
首选探索上限为 32,000 bytes/s（256 kbps），限制所有同实例替人数据的总准入，
外层封装与重传可使物理网络字节更多，不把此额度表述为完整 QoS。

普通 LAN 生命周期仍由社区成员身份控制。中继控制面故障、语音故障或离开
语音房均不应关闭虚拟网络。本机正额度必须持续刷新短租约；停止刷新后原生
单调时钟使其失效。关闭先清零本机，再尝试撤回后端资格；失败自动重试。
新节点仅在有效租约期间广播可中继偏好，实际远端路由收敛没有承诺固定时限。

邀请和 DNS 目录已部署；用户随后明确批准开启成员中继服务端开关，现 Gryt
`LAOKUAI_MEMBER_RELAY_POLICY_V2=1`、管理代理 `MEMBER_RELAY_POLICY_VERSION=2`。
仅 Gryt 与管理代理重启，ET、SFU、带宽和语音参数保持；未替用户创建 true 凭据。
客户端主动同意仍默认关闭，现有 .7 包可在联机设置中开启实验测试。
见 [服务端启用回执](../release/acceptance/member-relay-enabled-20261013.json)。
真实多设备 DNS、游戏、中继和 12 个完整客户端语音仍需实测；开关和只读健康
通过不等同转发验收。关闭时先清零本机额度，再撤回后端资格；关服务端 gate
仍需在线 false 回读或离线 TTL 到期，不保证远端 WAN 立即收敛。
