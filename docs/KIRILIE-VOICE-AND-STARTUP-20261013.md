# 奇丽叶主题、中文事件播报与管理员启动

本轮是在已交付 `.8` 易记 DNS 版本之上的客户端改动。生产 Gryt、SFU、
EasyTier 和管理代理不因外观或声音更新而重新部署。最终包身份及验证结果
以 `release/manifest.json` 和对应验收回执为准。

## 外观

设置中的“主题”提供“手绘奇丽叶”和“原主题”。奇丽叶默认使用奶油色纸页、
嫩绿和花黄色、柔和铅笔边框及原创花朵星星装饰，覆盖主界面和弹出菜单。
装饰不阻挡点击，状态、错误与焦点仍保留清晰对比。

主题风格独立保存。切回原主题恢复此前的深浅色和自定义配色，保留侧栏宽度、
缩放和字号等个人设置。用户提供的参考截图及其水印不随应用分发。

## 中文事件播报

语音设置中可以选择声音包，并逐条试听。含完整九条音频的测试包默认选择
曼波中文人声；不含这些可选音频的源码构建使用经典提示音。原来导入的
连接、断开音频优先保留，也可以逐事件导入自己的音频。

| 事件 | 播报 |
| --- | --- |
| 已连接语音频道 | 已连接到语音频道 |
| 语音连接终止 | 已断开语音连接 |
| 成员加入当前频道 | 有成员加入了你的频道 |
| 成员离开当前频道 | 有成员离开了你的频道 |
| 管理员移动成功 | 你已被移动到另一个频道 |
| 麦克风静音 / 恢复 | 麦克风已静音 / 麦克风已开启 |
| 关闭 / 恢复语音声音 | 语音声音已关闭 / 语音声音已开启 |

播报依据已确认的状态或事件触发，不把点击“加入”当作连接成功。短暂恢复
过程保持安静；切换频道会取消旧队列，队列有长度、去重和超时限制。
播报沿用通知输出设备、音量和开关，不进入麦克风媒体处理链。
主动关闭语音声音时仅保留一次本机操作确认；免打扰、服务器禁听和总输出
音量为零仍抑制播报。其他成员事件及试听在语音声音关闭时保持安静。

这套声音在制作包时由 MiloraAPI 预生成，用户已确认样本音色。九条 PCM WAV
共 1508574 字节，单条约 1.48–2.04 秒，客户端运行时不调用 TTS 服务，不需
API Key、模型、GPU 或额外付费。此次测试音频位于 Git 忽略的私有构建目录，
公开仓库保留播放器、事件文案及可选声音包接口；不把工具代码的 MIT 许可
描述为角色音色或生成音频的公开分发授权。

后续音量修复：含完整曼波包且未保存播报音量时，九条播报默认均为 75%。
原来的连接／断开 30% 经通知音量曲线仅剩 2.7% 振幅（约 -31.4 dB），
75% 为 42.2% 振幅（约 -7.5 dB）；没有增加超过原音频的增益或修改 WAV。
试听和实际播报沿用同一音量曲线及输出设备。经典提示音仍默认连接／断开
30%、成员进出 60%；已有自定义连接／断开音频保留经典默认。
所有已保存音量（包括旧 30%、成员 60% 和 0%）、开关、免打扰与输出设备
保持原值，不根据数值猜测是否由用户主动设置。仍感觉小声时，在语音设置
下方调整连接／断开和成员进出音量；连接／断开的恢复默认按钮使用当前
声音包的默认音量。此修复的自动检查验证默认加载、实际播放器增益、九条
试听与播报一致以及静音/路由取消，不能代表用户设备上的主观听感验收。

项目来源：[xmimu/manbo-tts](https://github.com/xmimu/manbo-tts)、
[MiloraAPI 文档](https://api.milorapart.top/docs/45/mbAIsc)。本地推理备选为
[Tsukimisaka/MamboTTS](https://github.com/Tsukimisaka/MamboTTS)。

## 管理员启动

固定目录绿色包在非管理员状态下提供“以管理员身份重新启动”和“退出”。
只有用户主动选择后才通过 Windows 正常 UAC 重新启动同目录应用。取消授权
后退出，不循环请求、不安装服务。失败时保持明确提示。

重新启动只保留已允许的配置目录和网络规则清理参数；不把任意启动参数或
外部可执行路径交给提权进程。普通双击到管理员重启仍需用户在 Windows
UAC 中确认；纯测试通过不等于真实 UAC 交互或多设备网络验收。
