# .16 语音纠偏与交付边界

用户授权：在 .15 双人失败调查后，按收拢控制和保持联机独立的方向纠偏、更新。
本记录描述候选实现，是否已交付以 release/acceptance 的精确回执为准。

## 控制归属

- 主进程社区运行时拥有 EasyTier 生命周期。加入、退出语音和选路不得启动、
  停止或替换 ET；语音读取 ET 路径观测，观测缺失不冒充核心离线。
- HybridRouteController 是每个远端接收通道的选路控制者。Peer 只负责连接、
  实际媒体和路径观测；界面、诊断和服务端协议 ACK 不单独选择播放源。
- 保持 SFU 首先播放。P2P 必须提供新鲜解码及允许的路径，在本地交接成功后
  才申请暂停对应 SFU 下行。恢复仍由同一控制器处理；服务端暂停到期自动放行。
- 区分切换所需的新鲜媒体和已经在通话时的连续性容忍；等待新采样使用所属
  探测/切换阶段预算，不以一次监控周期代替阶段超时。不新增重试状态机。

## 本次修复

1. 按固定 EasyTier 2.7.0 ProtoJSON 契约接收省略的空连接列表；凭据观察与
   网络解析采用相同来源，避免合法间接路由使全部地址和状态消失。
2. 收拢 Peer 和控制器的新鲜度约束，旧缓存等待真实解码增量；停包仍保留或
   恢复 SFU。增加生产方法组合的延时回归，避免模拟对象刷新时间戳掩盖问题。
3. 已认证本地成员能够释放自己拥有的旧配对，不要求离开的远端继续在线认证。
   保留本地权限、房间代次及配对所有权检查。
4. Gryt、SDK 到本地诊断保留固定协议拒绝码，禁止输出任意错误文本；客户端
   显示层和落盘层复用同一原因枚举，移除重复定义。
5. SFU 初次协商、重新协商和移频采用同一麦克风编码配置。

## 更新范围

客户端 .16 使用重新构建并固定的 SDK。桌面只替换程序文件，先完整备份、
逐项校验账号数据和配置；不替用户启动程序。服务器只更新 Gryt 与 SFU 镜像，
保留最新全部 Compose overlays、环境、端口、成员、聊天、12 人限制和中继开关。
EasyTier、管理代理及其他服务不重启。当前 16 kbps / 60 ms SFU 参数保持。

旧包和旧镜像保留回滚材料。不得以旧回执或源码检查声称新版已通过真实
双人连续通话、听感、游戏或 12 人 WAN 验收。尚未定位的双端配对失效与听感
问题用精确诊断继续验证，不以追加复杂状态机掩盖。

真实 Go/ICE 测试须在隔离容器执行，不在用户通话的 Windows 桌面上启动。
