# 精简分发与固定目录单 EXE

当前仍使用 Electron + EasyTier 2.7.0。`.14` 完整 ZIP 为162,765,292字节，
释放后395,078,300字节。其中Electron主程序214,117,376字节，应用ASAR约60MB，
EasyTier core与CLI合计约26.4MB。压缩改善下载体积，不减少运行内存。

## 本轮处理

检查发现 `dist-electron` 混入四个旧的 `main-*.js`，合计约11.3MB。
所安装 `vite-plugin-electron` 默认不清空输出，多个入口顺序构建。现在仅第一个
入口清空共享输出，后续入口继续写入；包审计也拒绝未被入口引用的旧主进程块。
`.15` 保持语音、联机、主题、录音和用户数据逻辑，只更新构建与分发。

同一`.14`完整程序的7z对照包为98,251,996字节，相比原ZIP减少39.6%。
`.15` 的最终ZIP/7z大小及逐文件一致性以对应回执为准。
`tools/new-compact-package.ps1` 将已经通过审计的程序压为7z，再解开逐项验证
全部文件哈希；不裁剪功能、驱动或许可证，不运行程序或修改桌面。
解压器支持7z时可使用精简包；解压后的应用仍为固定目录，兼容原增量更新方式。

## 单 EXE 的可行边界

现有 electron-builder 便携模板默认把程序写到 `$PLUGINSDIR/app` 或
`$TEMP/<unpackDirName>`，每次运行前与退出后删除；仅设置unpackDirName仍是临时
目录，不能满足此需求。它是自解压封装，不是所有组件直接在一个文件内运行。

可采用专用启动器：将运行文件首次释放到EXE旁的固定子目录，后续校验版本后
直接复用；用户数据独立保存且不随更新删除。更新须等自有应用完全退出再替换，
保留回滚，并延续正常UAC及固定路径防火墙规则。这样可以单文件分发而不向系统
临时目录释放应用，但磁盘上仍有运行目录；首次启动也要等待解压。

本轮交付精简压缩包；上述固定目录启动器尚未实现或验收，不把现有临时目录
portable.exe重命名成“免解压版”。真正保持一个文件且完全不落地，不能直接由
现有 Electron/独立EasyTier/驱动组合的打包参数实现。
