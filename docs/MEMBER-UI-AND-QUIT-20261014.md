# 成员拖动、响度显示和退出诊断

本轮目标版本 `.14`，基于 `.13`，Voice SDK 仍为 routing.5。未改媒体选路、
自动响度 DSP、手动成员音量或社区 EasyTier 生命周期预算。

## 管理员移动成员

频道内语音成员卡片支持拖到另一个语音频道。入口复用原有服务端移频事务，
要求社区能力、成员客户端 staging 能力、管理权限、严格角色高低及唯一在线
语音设备；源/目标、连接代次和权限变化后在放下时再次校验。等待服务端确认，
不抢先修改成员列表，也不把管理员自己的语音连接切到目标频道。

拖动成员与频道排序分别处理；成员音量、菜单和按钮保持原操作。文本频道、
原频道、跨社区或过时成员卡不会触发移频。实际目标端准备、提交、音频恢复
仍须双人测试；浏览器夹具不能代替真实网络验收。

腾讯云既有 Gryt/SFU 镜像已经实现协议，但此前未设置服务端开关。用户明确
授权后，仅开启 `VOICE_ATOMIC_MOVE_ENABLED=true` 并重启 Gryt；未替换镜像，
既有九项 Compose 文件、环境、端口、挂载、12人上限和中继开关保持。
SFU、EasyTier、管理代理与其他容器代次未变。匿名读取 `server:info` 确认
能力为 true，包含 Gryt 对 SFU 的协议确认；未登录账号或移动真实成员。
见 [部署方案](../release/deployment/voice-member-move/README.md) 和
[启用回执](../release/acceptance/voice-member-move-enabled-20261014.json)。
后续部署必须保留 `/opt/stacks/gryt/voice-member-move-20261014-r1/activation.overlay.json`。

## 响度均衡

原来的零刻度圆环改为双向补偿条、增大/减小文字与明确 dB 数值，保留学习中、
稳定、受限、等待讲话、未测量和已停用状态。首次尚无语音样本时不把初始零值
伪装成测量结果。常驻条展示已学习补偿，悬停/键盘焦点详情另列当前应用补偿。
停说时正增益可能暂停，但已学习数值仍保留。此显示仅代表接收端自动补偿，
不包含手动音量与压缩器；用户手动调节仍独立生效。

## 退出等待

用户报告首次托盘退出需要等待数秒，未确认期间桌面是否可操作。旧实机日志
没有退出阶段记录，不能认定 Windows 卡顿，也不能宣称已修复具体耗时根因。

新增固定枚举阶段和单调时钟耗时，覆盖托盘请求、UI关闭请求、自有核心与
凭据撤销、DNS排空、防火墙等待、配置刷新和最终收尾；不写身份、地址、凭据
或任意原始异常。诊断写入失败不妨碍退出，单项清理同步抛错也不跳过其余任务。
保留原有安全清理预算，不靠提前杀进程缩短等待。

`ui-retire` 表示窗口关闭请求返回，不等于屏幕已消失；凭据阶段含原生停止及
后续撤销等待，最终记录表示同步收尾完成，不代表 OS 已回收进程。核心停止、
撤销和 DNS 存在秒级超时预算，可能解释后台等待，但仍需新版实机退出日志验证。

## 验证边界

类型、定向 lint、核心契约、真实离线浏览器交互、两种主题的响度渲染、退出
失败与重入检查用于防止回归。实际检查数量、完整包与增量包哈希以本版回执为准。
打包与离线夹具不访问真实账号、不采集设备麦克风、不启动 EasyTier/TUN。
桌面更新前完整备份，增量后逐项核验用户文件不变；不会自动启动客户端。
