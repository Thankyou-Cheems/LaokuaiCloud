# 现有客户端的原生局域网语音分支

分支 `codex/native-lan-voice`，基于 `5d5cdf4e0bad41073b4b8f750872e0ea55416098`。
用户明确否定独立手填 IP 的实验面板；本轮交付对象改为原有唠蒯云客户端。
保留 Electron、社区认证、成员目录、MagicDNS、频道界面和管理权限。
不覆盖桌面 .16，不迁移或重置账号，不改变生产服务。

## 一条音频路径

恢复社区仍由现有 CommunityEnrollment 独立维护 EasyTier。进入频道后，
客户端从主进程取得当前设备的 grant 标识，提交已认证的频道加入请求。
Gryt 控制面验证账号、频道权限、12 人席位和该设备的 EasyTier 绑定，
私下给同频道各端发送虚拟 IPv4、会话密钥和成员列表。用户不用手填地址或密钥。
成员目录的“分配过地址”不等同于设备当前入网，也不用于替代绑定验证。

客户端在固定路径启动 C++ AoO / Opus / PortAudio 进程，绑定自己的社区虚拟
IPv4 和 UDP 39177，按频道名单自动向对端虚拟 IP 发送音频。实际直连或中继
由 EasyTier 路由；此分支不创建 WebRTC、ICE、STUN、TURN 或 SFU 音频连接。
腾讯云 Gryt 仍负责认证与频道控制，不转发本分支媒体。

默认 48 kHz 单声道、32 kbps Opus、20 ms 编码帧、120 ms 接收缓冲。
这是实验默认值，不是实测端到端延迟。AoO 关闭内建公网发现/穿透，外层包有
HMAC 和重放检查；链路加密由 EasyTier 提供。房间密钥只留在内存和子进程管道，
不写账号配置、公共成员广播或日志。当前使用房间共享密钥，并非每个说话者独立签名。

离开频道、断开社区、撤销权限、授权租约到期会停止音频；不停止 EasyTier。
心跳维持短期音频租约，正常刷新不重启音频进程。成员进出需要更换房间密钥，
当前实验通过重建音频会话执行，可能有短暂间断；不能称为无缝多人热加入。
静音、耳机静音、输入/输出音量和单成员音量通过进程命令更新。
管理员移频沿用现有权限检查，更新源和目标频道的媒体成员。

## 已明确的限制

- 原生采集/播放暂用 Windows 默认设备；原 WebAudio 的自动门、RNNoise、
  AGC、压缩器、自动响度均衡不接入本引擎，界面明确显示不可用，不能假装设置生效。
  建议使用耳机；本实验没有声学回声消除。
- 真实遥测包括原生进程状态、采集/播放电平和 UDP 包数量。包数量不证明对方
  已播放声音，EasyTier 路由也不等同于媒体质量或物理直连。单成员语音电平未接入。
- 语音仅限社区音频频道，不支持私聊通话、摄像头或屏幕音频。
- 12 人全互联若全部经过同一台 6 Mbps 中继，仍可能超过服务器出口；现有
  离线容量测试不能证明满足该带宽约束。先完成双机，再验证真实多人和中继预算。
- 生产 Gryt 未启用原生协议时，新客户端明确提示后端未启用，不能直接与旧版
  WebRTC 客户端互通。部署时需要安排双方同时使用本分支。

## 构建与验证

原生依赖固定在 `experiments/native-audio/dependencies.json`，保留许可证和
对应源码链接。执行 `tools/build-native-lan-audio.ps1` 生成 sidecar、运行离线
编解码与边界检查并更新哈希；然后按 `tools/build-portable.ps1` 编译/打包。
打包必须先提交精确源码，包内 SOURCE-OFFER 指向该提交，不能指向旧 main。
helper 不运行时解压，也不需要用户安装 PowerShell；沿用固定目录绿色包。

本轮检查重点是实际编解码、频道权限/成员生命周期、进程退出和真实调用边界，
不以静态字符串匹配替代联网验收。已有测试首次发现的接线失败也保留结论：
旧 VM 测试把 hook 的包路径写死，需要随 facade 接线更新；多人混音容量检查
曾容忍大量削波，需要增加输出限幅验证；媒体状态和成员广播间可能互相反馈，
必须只在状态变化时上报，防止触发限流或循环刷新。

类型和 VM 检查通过后，真实 Electron 隔离启动还发现一个遗留 WebRTC hook
依赖导致错误页。`tools/check-native-lan-ui.ps1` 以全新 profile、隐藏窗口、
离线 origin 和禁止设备权限启动编译产物，检查错误边界和真实 preload 模式；
它不读取桌面账号，不代表麦克风或网络验收。

真实声卡、Windows 防火墙、两台 EasyTier 节点、持续听感和退出耗时仍须测试。
本分支开发检查不启动真实设备、改生产开关或操作用户当前桌面应用。

本地完成：核心检查（含新增原生 runtime/IPC/频道/热键/facade）、客户端完整
类型/定向 lint/桌面编译、服务端类型/lint 和 84 项行为检查；其中 17 项针对
原生频道协议。原生 runtime/IPC 17 项、helper 134 项自检及实际 AoO/Opus
离线场景通过。3/12 节点输出限幅后硬削波计数为零；仍不代表真实听感合格。
最终真实 Electron 隐藏离线启动显示原生 preload 模式和正常空社区界面，
未出现错误页；仅访问全新隔离 profile，网络和设备权限被禁止。
旧 `check-voice-policy-stability.mjs` 依赖历史提交 `701200d0`，该提交在此前
授权重写历史后已不可达，因此该历史对照未运行成功，不计入通过项。
