# 原生音频实验 1：交付与证据

用户明确要求先做「原生音频通过 EasyTier 虚拟 IP」的实验，再决定是否去掉
Electron。已新增独立 `experiments/native-audio/`，不切换现有客户端架构。
桌面 .16、账号、配置、生产 Gryt / SFU / ET 均未修改，内部 .17 候选也未发布。

## 实现

- C++17 AoO source/sink + Opus + PortAudio；禁用 AoO 内置网络、发现、STUN 和服务器。
- Windows WASAPI 默认设备优先；支持单声道输入或双声道降混，以及设备双声道输出复制。
  默认 48 kHz / 32 kbps / 20 ms 编码，10 ms 回调，120 ms 初始缓冲。
- 明确绑定 `10.203.217.x:39177`，只向配置的同网段对端发送。现有 EasyTier 决定物理路由。
  无 WebRTC、无 SFU、无自动路径切换，也不管理或重启 EasyTier。
- 一次性实验密钥、HMAC 包认证、限长与重放窗口；密钥仅 stdin，不保存到 profile/日志/命令行。
  这是隔离实验控制面，不冒充社区正式成员授权。外层认证不提供音频加密，依赖 ET 隧道配置。
- WinForms 双击界面只有点击开始才启用麦克风和 UDP。普通权限，不装服务、不自动改防火墙。
- 退出只关闭自己创建的 helper。Windows 对端尚未监听的 ICMP 错误不会直接终止音频。
  音频时戳以初始 NTP 加单调时钟推进，避免系统校时导致音频时钟突然倒退。

固定依赖及构建方法见实验目录，未修改上游源码。使用 AoO 2.0-pre4，并非成熟性保证。
当前 FEC / DTX 保持上游默认关闭；重传、丢包隐藏不能冒充 FEC 已启用。

## 已实际执行的本地验证

[结构化回执](../release/acceptance/native-audio1-offline-20261014.json)记录本次结果。
没有调用声卡或 OS socket，没有偷偷录制用户声音，没有使用 GitHub Actions。

合成 PCM 经过实际 AoO / Opus 编解码和内存数据报队列，而不是模拟「播放成功」状态。
24/32/48/64 kbps 双端测试、10% 丢包与 25 ms 乱序、100/200 ppm 独立时钟偏差、
1 秒中断恢复、3 节点混音和 12 节点容量检查通过。另用 6 kHz 信号验证电话频段
以上的信息能够穿过当前编解码链路；32 kbps 探针相关纯度 0.999491，不等于主观听感验收。

1 秒中断测试先观察到解码静音，恢复后首个有效输出出现在模拟 20 ms；末尾也检查持续
解码相关性。这不是网络或声卡端到端恢复时间。高电平同相混音故意触发限幅，验证有限输出；
不能把限幅通过说成多人同时大声说话仍无失真。8 MiB 只是 AoO 实时内存池配置，未测总进程峰值。

helper 129 项纯内存边界检查通过，覆盖地址、参数、认证、篡改、重放、会话重启及
Windows UDP 暂态错误分类；4 项真实 stdin 子进程检查确认缺少 start 时拒绝启动，且不回显密钥。
界面纯自检和隐藏布局检查通过。原生 helper 静态链接运行库，仅依赖 Windows 系统 DLL，
测试者不需要安装 C++ 运行库或 PowerShell 7。

AoO 在启动时先收到 ping、尚未收到 source start 的 warning 保留在本地完整测试输出，
没有为了好看过滤失败证据。实际调用、有限样本、输出能量和目标信号相关性共同判断通过。

## 带宽结果与未验证项

12 节点 10 秒内存实验发出 71,815 个 AoO 数据报，共 10,292,840 字节（132 个方向累计）。
理论数据包为 132 × 50 × 10 = 66,000，余量含控制数据；没有发现随人数额外指数增长。
这个数据量已经约 8.23 Mbps，尚未计外层认证、UDP/IP 和 EasyTier，不能全部经 6 Mbps
服务器中继。实验目前采用易检查的 OSC 包，32 kbps 是编码目标，不是最终线路码率。
真实上线前需测量语音内容、静音发送、协议开销和中继比例，再决定节流及多人分发方式。

仍待用户执行真实双机 EasyTier / Windows 防火墙 / 声卡通话；随后验证长时间运行、
真实短断网恢复、游戏并行、真实中继、设备拔插与 12 人。不能以这些离线结果宣布
音质或稳定性已经超过现有 WebRTC，也不能据此删除 Electron。

源码和包分开发布，包中保留许可证、精确源码提交与上游固定版本。ZIP 可用 Windows
资源管理器直接解压。使用方法见 [实验说明](../experiments/native-audio/README.md)。
