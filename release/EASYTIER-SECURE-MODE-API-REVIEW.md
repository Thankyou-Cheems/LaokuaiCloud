Verified GenerateCredentialRequest fields: groups, allow_relay, allowed_proxy_cidrs, ttl_seconds (>0), optional credential_id, instance selector, optional reusable. GenerateCredentialResponse: credential_id UUID, credential_secret base64 private key, expiry_unix. RevokeCredentialRequest: credential_id plus instance; response success. List returns credentials with groups/relay/proxy/expiry/reusable and public_key_fingerprint. The latter is not a full Noise public key; do not substitute it as peer_public_key.

Important refinements: CLI reusable defaults true, so per-device policy must explicitly pass --reusable false or RPC reusable=false. Optional credential_id is documented idempotent; do not assume re-generating the same ID extends TTL without verifying service behavior. CLI --output json is implemented: one selected result is a direct response object; multiple instances return wrappers containing instance_id/instance_name/result. Always pin an exact network instance and reject ambiguous/multiple results. Normal text output prints credential_secret; an adapter must use captured JSON and never log its output.

Core --credential maps to SecureModeConfig enabled=true and local_private_key=credential_secret; no network_secret is needed for that temporary node.
