# EasyTier 原生语音实验 1

这是独立的 Windows x64 实验程序。现有唠蒯云负责登录社区和维持 EasyTier；
实验程序使用本机虚拟 IPv4，通过 UDP 向指定成员传送 AoO / Opus 音频。
不启动或重启 EasyTier，不参与现有 WebRTC / SFU 选路，不读取或修改账号与配置。
Electron 暂时保留，是否替换由真实双机及多人测试结果决定。

## 双机使用

1. 双方照常打开唠蒯云，等各自显示「已入网 · 本机」。记下双方 `10.203.217.x` 地址。
2. 退出旧版语音频道，但保持唠蒯云运行，以维持 EasyTier。双方佩戴耳机。
3. 解压实验 ZIP 到独立固定文件夹，双击原生语音实验 EXE。无需 PowerShell 或额外安装。
4. 各自选择自己的虚拟 IP，填写对方的虚拟 IP。多人实验需每人填写其余参与者。
5. 一人生成实验密钥并私下发给另一人；双方填入同一个密钥。它只用于本次实验，
   不要填写社区密码。程序不保存密钥；停止后需要时可继续使用当前窗口的值。
6. 点击「开始」。只有这时才打开麦克风和 UDP。若 Windows 询问网络访问，按系统提示允许。
7. 观察输入/输出音频及收发计数，轮流说话，再同时说话。双方都应听到清晰声音。
8. 「停止」或关闭窗口会停止实验音频；EasyTier 和原唠蒯云继续运行。

初版只接受本社区 IPv4 地址，不做 MagicDNS 查询，不自动改防火墙。
双方密钥、UDP 端口（39177）和对端地址必须一致。Ping 成功不等于 UDP 一定放行；
单向音频要分别记录发送、认证接收、解码输出和设备异常计数。
程序绑定虚拟地址；EasyTier 决定其物理直连或中继，本工具不将 UDP 到达标成物理直连。
实验认证要求两端系统时间相差不超过 30 秒；若重放拒绝持续增加，先检查系统时间。
单次运行最多接受每位对端的 8 次新会话，频繁重启超过此数时双方停止再开始。

## 音频与边界

- 固定 48 kHz、单声道、Opus 32 kbps，目标编码帧 20 ms，初始接收缓冲 120 ms。
- AoO 负责时钟适配、缓冲、编解码和重传；此固定版本的包装层没有开放 FEC / DTX
  控制，二者保持上游编码器默认关闭，不能把 PLC 丢包隐藏或重传称为 FEC。
- 实验不启用 RNNoise、自动门、AGC 或回声消除。请使用耳机；暂不比较扬声器回声表现。
- 对指定对端的 UDP 包有独立 HMAC 认证与重放窗口；不使用公网信令或 STUN。
  HMAC 本身不加密音频，虚拟网络链路的加密由现有 EasyTier 配置承担。
- 共享实验密钥不替代正式频道成员授权。该工具还没有接入社区权限、踢人、移频和成员自动发现。
- 最多配置 11 个对端，表示可构造 12 人全互联实验，不表示已经通过 12 人验收。
  12 人全同时说话共有 132 份有向音频流；仅 32 kbps 编码就需要 4.224 Mbps，
  还有 AoO、UDP、认证、EasyTier 等开销，不能保证全走 6 Mbps 服务器中继仍够用。

## 验证顺序

先分别测试单向和双向声音、静音/恢复、停止/再次开始，以及只退出实验时 EasyTier 是否继续在线。
记录 10 分钟持续通话的断音次数与听感，再测试网络短暂中断后是否自动恢复。
通过双机后再扩展到 4 / 12 人，分别验证真实直连和中继、游戏同时运行、不同声卡和设备拔插。
离线音频模拟不能代替真实声卡、Windows 防火墙和 WAN 验收。

## 开发和复现

需要 PowerShell 7（仅开发者）、Git、CMake 4、Visual Studio 2026 C++ 工具和 Windows SDK，
以及系统 .NET Framework C# 编译器。运行：

```pwsh
./experiments/native-audio/build.ps1 -Fetch -Test
```

AoO、Opus、PortAudio 固定版本见 `dependencies.json`。脚本拒绝版本不符或被修改的依赖，
不改写已有 checkout。所有下载与构建产物位于 `.local/`，不进入公开 Git。
上游 AoO 基线是 2.0-pre4，属于预发布版本，不能据此声称比 WebRTC 更成熟。

`native-audio-offline.exe` 将合成 PCM 经实际 AoO / Opus 编码、内存网络、解码，
不访问声卡或 OS socket；`laokuai-native-audio.exe --self-test` 验证协议/认证边界，
不建立真实网络。所有自检均在本地执行，不消耗 GitHub Actions。
